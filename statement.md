# Project Statement

## 1. Project Title

**Student Management System**

---

## 2. Problem Statement

Managing student information manually can become difficult when records need to be added, viewed, searched, updated, or deleted.

The **Student Management System** provides a simple command-line solution for organizing basic student records. The system allows users to maintain information such as roll number, name, age, course, and marks through a menu-driven Python application.

The project applies fundamental programming concepts to a practical problem and provides separate operations for managing student records.

---

## 3. Scope of the Project

The scope of the project includes the basic management of student records through a command-line interface.

The system currently supports:

- Adding new student records.
- Displaying all available student records.
- Searching for a student using the roll number.
- Updating existing student information.
- Deleting student records.
- Exiting the application through the main menu.

Student information is currently stored temporarily in an in-memory Python list. The current scope does not include permanent database storage, authentication, or a graphical user interface.

---

## 4. Target Users

The primary target users of the system are:

- **Students** — for understanding and demonstrating basic student-record management.
- **Teachers/Faculty** — for demonstrating the use of a simple digital student management application.
- **Academic Project Evaluators** — for evaluating the implementation of Python programming concepts and CRUD operations.

---

## 5. High-Level Features

### 5.1 Add Student

Allows the user to enter and store:

- Roll number
- Name
- Age
- Course
- Marks

### 5.2 Display Students

Displays all student records currently stored in the system.

### 5.3 Search Student

Searches for a student using the student's roll number and displays the matching record.

### 5.4 Update Student

Allows the user to modify the name, age, course, or marks of an existing student.

### 5.5 Delete Student

Removes a student record using the student's roll number.

### 5.6 Menu-Driven Interface

Provides a simple menu through which the user can select the required operation.

---

## 6. Project Boundaries

The current version is a basic command-line application. It focuses on demonstrating student record management and fundamental Python programming concepts.

The following features are outside the current implementation:

- Permanent database storage.
- Graphical user interface.
- Web-based access.
- User authentication and authorization.
- Automated testing framework.
- Advanced reporting and analytics.

These features may be considered as future enhancements.

---

## 7. Expected Outcome

The expected outcome of the project is a functional Python-based Student Management System that allows users to perform basic operations on student records through an interactive command-line menu.

The project demonstrates the practical application of functions, lists, dictionaries, loops, conditional statements, user input, and CRUD operations.
